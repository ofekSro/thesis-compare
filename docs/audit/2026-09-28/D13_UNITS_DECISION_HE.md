# D13 — "חסר־ממד": הכרעה ותוכנית שינויים (2026-09-28)

סטטוס: **ההכרעה התקבלה (אפשרות a). השינויים בקבצים טרם בוצעו** וממתינים לאישור
הבעלים לפי קבוצה (A/B/C/מועמדים, סעיף 6). מקורות: ממצאים PHY-07, ALG-10,
CHO-13 ו־SUMMARY D13 (‏`docs/audit/2026-09-27/`), קובץ הבעלים "קבוצות פאי.docx"
(מחוץ לריפו), חוות דעת סוכן הפיזיקה מ־28.9 וחישוב מספרי שבוצע בסשן.

## 1. הבעיה

קבוצות הניבוי שנבחרו הן ‎ρ = b²/(b+s)²‎, ‏H/s ו־‎Π₂ = s/W^⅓‎. ‏ρ ו־H/s חסרי ממד.
‏Π₂, וגם ‎Z = R/W^⅓‎, נושאים יחידות m/kg^⅓ ולכן אינם חסרי ממד. הקוד והמסמכים
טוענים "all terms dimensionless". הטענה הזו לא נכונה.

## 2. גזירת באקינגהאם (טיוטת הבעלים) — נכונה, פרט לשורה האחרונה

- משתנים: ‏R_c [L], ‏E = W·e_TNT [ML²T⁻²], ‏p0 [ML⁻¹T⁻²], ‏s, b, H [L]. ‏n = 6.
- שורות M ו־T במטריצת הממדים פרופורציוניות (T = −2M), לכן הדרגה היא k = 2
  ומתקבלות 6 − 2 = 4 קבוצות.
- ‏E ו־p0 בלתי־תלויים ממדית ולכן משתנים חוזרים תקינים. ‎(E/p0)^⅓‎ הוא אורך
  סאקס (Sachs scaling; ‏R̄ של Baker, *Explosions in Air*).
- הקבוצות: ‎π1 = R_c/L0, π2 = s/L0, π3 = b/L0, π4 = H/L0‎. ההמרה ל־ρ ול־H/s
  הפיכה, ולכן הסט {π1, π2, ρ, H/s} שלם.
- **הטעות:** בטיוטה נכתב ‎(E/p0)^⅓ = W^⅓‎. הקשר הנכון הוא
  **‎(E/p0)^⅓ = k·W^⅓‎**, ו־k קבוע ממדי.
- **הסתייגות:** רשימת המשתנים לא מלאה. ‏R_conv תלוי גם ב־c0 ובקבועי הקריטריון
  (10 kPa, ‏20 Pa·s/kg^⅓). הפתרון הוא להצהיר עליהם כקבועי המחקר: אוויר בתנאי
  הסולבר, מטען TNT וקריטריון קבוע. הצהרה זו גם מגדירה את תחום התקפות.

## 3. קבועי המחקר (מהגדרות Viper-Blast — צילומי מסך מהבעלים, 28.9)

| קבוע | ערך | מקור |
|---|---|---|
| ‏e_TNT | 4.52·10⁶ J/kg | Charge → Energy |
| ‏p0 | 101325 Pa | Atmosphere → Pressure |
| ‏T0 | 288 K | Atmosphere → Temperature |
| ‏c0 | ≈ 340 m/s | ‎√(1.4·287·288)‎; הבעלים אישר להניח 340 |

‎**k = (e_TNT/p0)^⅓ = (4.52·10⁶/101325)^⅓ = 3.54656 m/kg^⅓**‎
(‏1/k = 0.28196, ‏ln k = 1.26598, ‏√k = 1.88323).

מכאן ‎Π₂ = k·Π₂,S‎ ו־‎Z = k·Z_S‎, כאשר S מסמן את צורת סאקס חסרת הממד.
הערך שבו השתמשנו קודם, 4.184 MJ/kg, נתן k = 3.45641, והוא כבר לא רלוונטי. הערך
הנכון הוא האנרגיה שהסולבר משחרר בפועל.

**אורך סאקס:** ‏L0 = k·W^⅓ = **13.1 מ'** ב־W = 50 ק"ג ו־**40.6 מ'** ב־W = 1500 ק"ג.

## 4. המרת הקבועים לצורת סאקס (מאומת מספרית)

כל ההמרות מדויקות. בדיקה על קלטים אקראיים נתנה הפרש יחסי ≤ 4.5·10⁻¹⁶. **אין
צורך בהרצה מחדש.** התחזיות, השגיאות, CV/LOGO וכל הטבלאות זהים.
המקור: ‏`outputs/tables/final_production_*_req_soft3.csv`.

| מודל | קבוע | ‏m/kg^⅓ (רשומה) | סאקס |
|---|---|---|---|
| RadiusP רחוב | C0 / C3 / a | 10.0472 / 0.5319 / 1 | 2.8329 / 0.1500 / 0.2820 |
| RadiusP צומת | C0 / C3 / a | 11.7661 / 0.6999 / 2 | 3.3176 / 0.1974 / 0.5639 |
| RadiusP | היפוך איבר הקניון | Π₂ = 1 | Π₂,S = 0.2820 |
| RadiusI רחוב | A / r | 17.410 / 0.03437 | 5.187 / 0.05265 |
| RadiusI צומת | A / r | 16.327 / 0.07012 | 4.925 / 0.03644 |
| range_switch רחוב | C1 / A / B | 2.6798 / 3.0186 / 7.8188 | 0.7556 / 0.8511 / 2.2046 |
| range_switch צומת | C1 / A / B | 0.5619 / 2.1074 / 1.4108 | 0.1584 / 0.5942 / 0.3978 |

אלה הקבועים שנשארים ללא שינוי: C1 ו־C2 של RadiusP; ‏p, ‏q ו־r₂ של RadiusI; ‏C0
של range_switch; ‏C0, ‏C1 ו־C2 של canyon_trap.

הכללים להמרה:
- **RadiusP:** מחלקים את C0 ואת a ב־k. מחלקים את C3 ב־k, ונקודת ההיפוך עוברת
  ל־1/k.
- **RadiusI:** ‎r′ = r + 2·r₂·ln k‎ ו־‎A′ = A·exp((r−1)·ln k + r₂·ln²k)‎.
- **range_switch:** מחלקים את C1, ‏A ו־B ב־k. ‏**אזהרה:** האיבר ‎−ln Π₂‎ הוא
  בפועל ‎−ln(Π₂/P*)‎ עם ‎P* = 1 m/kg^⅓‎. כל המרה לסאקס חייבת לכתוב את P*
  במפורש. בלי זה ההמרה אינה שקולה והמודל משתנה.
- **canyon_trap:** ‎C3′ = C3·√k‎.

**הקריטריונים בצורה חסרת ממד:**
- רצפת הלחץ: ‎10 kPa / p0 = 0.0987‎.
- סף האימפולס: ‎20·c0 / (p0^⅔·e_TNT^⅓) = 0.0189‎ (עם c0 = 340.3). ‏W מצטמצם,
  ולכן הסף חסר ממד בדיוק לפי סאקס.

## 5. ההכרעה

**אפשרות (a) של D13.** הבעלים אישר אותה ב־28.9.
- **בתזה:** גזירת באקינגהאם עם E ו־p0 כמשתנים חוזרים, עם תיקון השורה האחרונה
  ל־k·W^⅓.
- **דיווח:** ביחידות המקובלות בתחום (m/kg^⅓, ‏"scaled distance", כמו ב־UFC
  3-340-02 וב־Kingery-Bulmash), לא "חסר ממד". יצוין ש־Z ו־Π₂ הם קבוצות סאקס
  חסרות ממד כפול k = 3.547.
- **נספח:** טבלת סעיף 4.
- **הפירוש הפיזיקלי:** "נקודת המעבר הפיזיקלית ב־s = W^⅓" יוצג כמוסכמת יחידות
  (0.28 בצורת סאקס), ‏a יתואר כנבחר ב־CV (CHO-13).

**אפשרויות שנדחו:**
- **(b), המרה מלאה של הריפו לסאקס:** לא משפרת את הדיוק. היא נוגעת בכל
  הטבלאות, במחשבון, ב־z_surface_3d ובבדיקות העוגן, ומסכנת את range_switch דרך
  P* המוסתר.
- **(c), התאמת נקודת המעבר:** החלטת מידול נפרדת שלא קשורה לשאלת היחידות.
  דורשת הרצה מחדש של שלב 2 ומזיזה את כל מספרי פרקים 9–10.

## 6. תוכנית השינויים (ממתינה לאישור לפי קבוצה)

**אף תוצאה רשמית לא זזה.** כל השינויים הם טקסט והערות קוד בלבד. הפרקים
התלויים בתזה: פרק 9 (מרחב הפרמטרים וניתוח הממדים) והפירוש של נקודת המעבר
בפרקים 9–10. מאמר ה־ISIEMS כבר קובע נכון ש־s̃ נושא יחידות m/kg^⅓. יש לבדוק בו
את המשפט "At s̃ = 1 m/kg^1/3 …".

**A — ‏ALGORITHM.md ו־ALGORITHM_HE.md (יחד, יישארו מיושרים)**
- **A1 (EN :36-45 / HE :32-40):**
  - הכותרת תשתנה ל־"Hopkinson-scaled framework".
  - לטבלה תתווסף עמודת יחידות: ‏ρ [–], ‏H/s [–], ‏Π₂ [m/kg^⅓].
- **A2 (חדש, אחרי A1):** תת־סעיף "Units and the Sachs form" עם סעיפים 2–4 של
  מסמך זה.
- **A3 (EN :60-63 / HE :53-55):** נימוק "Dimensional necessity" טוען שמאנרגיה
  ומרחק בלבד נשאר אורך אחד, W^⅓. זו טעות פיזיקלית.
  - הנוסח החדש: ‏E ו־p0 נותנים ‏L0 = (E/p0)^⅓, ובחומר ובאטמוספרה קבועים

  - ההיפוך יתואר ב־Π₂ = 1 m/kg^⅓ (0.28 בצורת סאקס), כמוסכמת יחידות.
